# paribu-cineverse-mcp 🇹🇷

سرور MCP غیررسمی و **فقط‌خواندنی** برای **پاریبو سینه‌ورس** (paribucineverse.com)، بزرگ‌ترین زنجیره‌ی سینمایی ترکیه — فیلم‌های در حال اکران و به‌زودی، جزئیات فیلم، سینماها بر اساس شهر و سانس‌های امروز هر سینما.

> بخشی از «کارخانه‌ی MCP ترکیه». هیچ وابستگی به پاریبو سینه‌ورس ندارد.

## برای ایجنت‌های هوش مصنوعی

```json
{
  "mcpServers": {
    "cineverse": {
      "command": "uvx",
      "args": ["paribu-cineverse-mcp==0.1.1"]
    }
  }
}
```

## ابزارها

| ابزار | توضیح |
|------|-------|
| `cineverse_list_now_showing` | فیلم‌های در حال اکران (۳۳ فیلم در ۲۰۲۶-۱۱-۰۷): نام، ژانر، تاریخ اکران، کارگردان، بازیگران، مدت، پوستر |
| `cineverse_list_coming_soon` | فیلم‌های به‌زودی (۲۶ فیلم در ۲۰۲۶-۱۱-۰۷) |
| `cineverse_get_movie` | جزئیات یک فیلم — ‏`film_url` (آدرس کامل یا مسیر سایت) |
| `cineverse_list_cinemas` | همه‌ی سینماها (۷۷ سینما در ۲۰۲۶-۱۱-۰۷) با شهر، آدرس و تلفن؛ فیلتر اختیاری ‏`city` |
| `cineverse_get_showtimes` | سانس‌های امروز یک سینما — ‏`cinema_slug` (مثلاً «14-burda»): برای هر فیلم ساعت سانس + فرمت + لینک خرید بلیت |

نکته‌ها:
- سانس‌ها مربوط به روز درخواست هستند؛ لینک‌های خرید به جریان بلیت‌فروشی خود سایت می‌روند (از اینجا خریدی انجام نمی‌شود).
- ‏`user_score_100` امتیاز تماشاگران «تخم‌مرغ طلایی» است (۰ تا ۱۰۰).
- داده: صفحات سرور-رندر سایت + JSON-LD اسکیما — بدون کلید، بدون لاگین، فقط‌خواندنی.

## قوانین

غیررسمی و فقط‌خواندنی — بدون لاگین، بدون کلید، بدون نوشتن. تست‌ها: آفلاین با فیکسچر + تست زنده (۱۷/۱۷ سبز).
